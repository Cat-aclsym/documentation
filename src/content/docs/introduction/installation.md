## Prérequis

- Installer [Git](https://git-scm.com/downloads)
- Installer [Godot 4.4](https://godotengine.org/download), en version standard (le projet est en GDScript, la version .NET n'est pas nécessaire). Le projet utilise le moteur de rendu Forward Plus.

## Récupérer le projet

1. Cloner le dépôt Git à cette URL `https://github.com/Cat-aclsym/Cat-aclsym_Claw_of_the_dead.git`
2. Ouvrir Godot et ouvrir le fichier `project.godot`. Le premier import des ressources peut prendre du temps.
3. Appuyer sur `F5` pour lancer la scène principale `res://scenes/main.tscn`

Dans l'éditeur, le projet s'appelle `Cat'aclsym` (nom défini dans `project.godot`).

Dialogic est fourni dans le dépôt (`addons/dialogic/`) : il n'y a rien d'autre à installer.
